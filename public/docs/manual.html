先看你想完成什么

工具箱是统一入口。内置能力、REST、MCP 和 APP 工具都是角色可以调用的不同来源。

需要手写“执行动作”吗？

通常不需要。你说清楚事情，角色负责生成动作和参数。为了让调用更明确，可以直接说“请使用本地资料库”或“请使用搜索工具”。

角色会自己查吗？

工具已开启、聊天预设也提供了工具入口时，角色可以在回复过程中自行决定调用。这不意味着每次聊天都读取全部资料，也不意味着它在页面关闭后持续运行。工具开关、模型、预设和运行环境都会影响实际行为。

当前普通聊天会检查预设是否包含工具入口；线下模式不走这套普通工具调用流程。初次体验请使用普通单聊。

03 / 调用与权限

角色何时能调用，怎样才算成功

先在普通角色单聊验证。工具名称与用途要进入当前预设，模型才知道可以用；打开工具开关不等于模型一定会选中它。

聊天环境对照
环境行为与条件
普通单聊启用工具，并确保当前生效预设含工具入口；默认条目名是“▸ 聊天工具箱”。自定义预设要保留对应工具宏。
群聊按具体发言角色执行；需要角色上下文的动作归到该角色。稍后主动联系不支持这个群聊上下文。
线下模式当前普通聊天工具流程禁用；不要拿线下模式判断工具是否配好。
自定义 APP / 工坊APP 有自己的可用工具范围和调用管线；普通聊天的内置能力列表不会无条件全部提供。工坊电脑与角色电脑有独立开关。
页面关闭不保证继续执行正在运行的 REST、MCP 或浏览器脚本。稍后联系、现实桥等专门离线流程还依赖推送订阅、个人云或服务端接管配置。

文本指令与原生工具调用

你始终可以用普通话。文本模式中，角色先输出 [获取指令:本地资料库] 获得动作定义，再输出具体动作。已经拿到的定义通常不必反复获取。配置支持原生工具协议时，宿主会走原生工具调用；不要求你或角色再手动展示方括号。

动作格式参考 · 给角色参考，不是用户强制执行命令
[获取指令:本地资料库]
[执行动作:列出资料目录({"path":"/","limit":10})]

群聊文本格式要带发言者，例如 ["角色名"执行动作:列出资料目录({"path":"/"})]。一次回复的动作应由同一个角色发起。动作参数用合法 JSON：双引号、数字不加引号、布尔值写 true / false。

界面上的“执行前确认”不是通用保险开关。

当前执行器只有“写入记忆”检查 confirm 并创建待确认请求。角色电脑、发送文件、现实桥、稍后主动联系没有对应的逐次确认分支，即使界面允许选这个模式，也不能据此保证弹窗。其他五项在界面中只提供开关并自动执行。本手册只说明现状，没有修改这些行为。

确认结果的四种方式

不要只看“已完成”三个字
操作要确认的证据
查询工具返回的正文、记录 ID、时间或来源链接，能与原资料对应。
写入 / 发布到实际目标检查：长期记忆、角色日历、公共便签墙或外部笔记。
命令 / 文件电脑命令检查退出码；文件真的能重读、打开或下载。success=true 不保证命令退出码为 0。
现实桥 / 延时联系分清“已排队”“已送达”“执行成功”“已收到回传”。预约成功也不保证角色到点一定发消息。

不希望角色主动翻查时

检查“本地资料库”，也检查组合区的“查你的手机”套件；其中日程、订单等脚本可直接读取浏览器数据，不完全依赖资料库开关。你自己添加的脚本和 APP 也可能有查询路径。只说“不要查”是提示要求，停用相应入口才会移除其能力；关闭这些工具不等于清空正常聊天上下文。

自动匹配同名动作的顺序是内置 → REST → 组合 → MCP → 自定义 APP。重名时可在组合步骤中指定类别、工具 ID 或 MCP 服务器 ID；普通聊天尽量使用互不重名的工具。

04 / 内置能力

小手机已经准备好的 10 项能力

统一入口：设置 → 聊天工具箱 → 内置能力。点开功能查看准备步骤、话术和结果位置。

开启前先分清执行方式

本地资料库、日历管理、网易云音乐、便签墙、工具箱管理，当前界面中开启后自动执行，没有逐次确认选项。实际只有写入记忆实现了 confirm 待确认分支；角色电脑、现实桥、发送文件和稍后主动联系不能依赖此选项保证弹窗。详见“调用与权限”。

01本地资料库查询小手机里的本地数据默认开启

能做什么：列目录、搜索、查看字段、读取文件或单条记录。范围包括角色卡、聊天、朋友圈、记忆、工具箱、设置和应用数据。

先准备：开启本地资料库，在普通聊天中使用。

查过去的约定
用本地资料库查一下我们聊过的“看电影”。只看相关聊天记录，告诉我约定了什么，附找到的原文。

检查结果：回答应对应实际查到的内容；有返回日期或记录标识时，可据此回到原聊天核对。

“文件”是小手机数据的虚拟目录，不是手机系统的照片、微信或任意文件。此工具提供读取与搜索；关闭它不会同时关闭正常聊天历史和记忆注入。访问范围也不能简单当作“只限当前角色”。

02写入记忆保存稳定、长期有价值的信息默认关闭

能做什么：把长期偏好、身份信息、重要约定、关系里程碑写入长期记忆。

先准备：开启写入记忆。源码默认模式为“执行前确认”；这个模式下需要确认请求后才落库。

保存偏好
请用写入记忆工具记住：我长期不喝咖啡，平时更喜欢喝茶。

检查结果：如有确认请求先确认，再到对应角色长期记忆中检查。

今天有点累、一次玩笑、角色的猜测等，不属于这个工具指导写入的长期信息。

03日历管理安排当前角色的日程默认关闭

能做什么：查看指定周，添加、修改或取消当前角色日程。

先准备：开启能力；说清日期、开始与结束时间。当前工具参数要求时间在 08:00–23:00，结束晚于开始。

添加一个安排
用日历管理，把明天 20:00–21:00 在家一起看电影加入你的日程。添加后再查一下，确认日期和时间。

检查结果：当前角色日程中出现安排。修改或取消前，让角色先查询原安排。

操作对象是小手机当前角色的日程，不会自动同步到系统日历、Google 日历等其他账号。

04网易云音乐让角色真的放歌、切歌默认关闭

能做什么：搜索、播放、暂停、继续、切歌，查看本地音乐库、网易云歌单和播放列表，也能向播放列表加歌。

先准备：开启能力；本地音乐需要已有歌曲，在线歌曲需要相应音乐服务配置可用。

直接播放
请用音乐工具播放周杰伦的《晴天》，直接播放给我听。找不到可播放的版本就告诉我。

检查结果：播放器当前歌曲改变并播放，不只是收到音乐分享卡片。

能否播放取决于音乐来源与权限；浏览器也可能要求你先点击页面才能播放声音。

05便签墙阅读和参与公共社区默认关闭

能做什么：查看便签列表、正文和评论，以角色身份发布便签或评论。

先准备：确认公共便签墙服务可访问，再开启能力。它不是私人便签本，发布动作会直接执行。

先试只读操作
用便签墙工具看看最新的五张便签，选一张读给我听。这次只查看，不发布也不评论。

检查结果：回答来自实际便签；若明确要求发布，可回到公共便签墙查看。

“只查看”是对角色的要求，不是系统权限开关；不希望角色具备社区操作能力时，应关闭此能力。

06现实桥连接真实手机的数据与快捷动作默认关闭

能做什么：查询你接入的电量、健康等现实数据，运行你登记的快捷指令。

先准备：在现实桥里配置对应数据或快捷动作，再到工具箱开启能力。开一个开关不会自动授予所有系统能力。

查询已接入的数据
用现实桥查看我手机最近上报的电量。如果有更新时间也告诉我，没有数据就直接说没有。

检查结果：数据与现实桥记录一致，注意可能是最近上报值；快捷动作要在真实设备上核对效果。

只能使用已经登记并能工作的能力，不能因此任意读取真实手机里的其他 APP。

07角色电脑保存文件，执行支持的命令默认关闭

能做什么：使用持久文件空间写日记、读旧文件、交付文件；在支持 shell 或容器的模式下运行相应命令。

先准备：进入设置里的角色电脑，按页面流程部署服务，填写地址和连接密钥，测试连接并允许角色使用。

保存一份日记
在你的角色电脑里写一份今天的日记，保存成 Markdown 文件。保存后重新读取一次，告诉我文件名和保存位置。

检查结果：能重新读取同一个文件。先看连接测试显示的基础、shell 或容器模式，再决定能否要求运行程序。

角色电脑是独立连接的环境。小手机部署在某台 VPS 上，不代表角色自动获得那台 VPS 的完整访问能力。

08发送文件把外部文件交付到聊天里默认关闭

能做什么：把外部 URL 指向的文件、音频或视频等作为聊天内容交付。

先准备：开启能力，准备可访问的实际文件链接，通常不能用登录后的网页代替文件直链。

替换占位文字后发送
请用发送文件工具，把这个链接的音频作为文件发给我：[在这里粘贴真实音频文件链接]。

检查结果：聊天里出现可打开、播放或下载的文件内容。

这个工具负责交付现有文件。生成图片、声音或制作文档，需要相应生成工具或角色电脑配合。

09工具箱管理让角色给自己添加工具默认开启

能做什么：创建、更新、启停或删除 AI 自己创建的 REST 工具、组合工具及套件。

先准备：开启能力，提供真实 API 文档和需求；密钥在设置中填写。

让角色配置一个接口
请使用工具箱管理，根据我接下来提供的 API 文档添加一个查询工具。地址、参数和返回字段必须以文档为准，不要编造。缺少密钥的位置留给我在设置里填写；先不要发送测试请求。

检查结果：工具箱中出现 AI 标记的工具；检查配置、补全密钥后，再要求角色测试。

系统拒绝修改你手动创建或受保护的内置内容。这套管理动作不等于自动部署 MCP 或注册外部服务账号。

10稍后主动联系约定过一段时间再来找你默认关闭

能做什么：在当前普通单聊中，设置若干分钟后的联系意图，到点后让角色判断是否发消息。

先准备：开启能力，在普通角色单聊使用；页面关闭后的接管依赖可用离线推送环境、订阅和安静时段设置。

约定稍后联系
用“稍后主动联系”设置 20 分钟后再来问问我：刚才那件事情做完了吗？

检查结果：先看到预约成功的工具结果，再观察到点行为。口头答应不代表已预约。

同一聊天只保留一个约定，新约定替换旧约定；到点后允许静默。它不是保证准点响铃的闹钟，也不是任意工具的后台定时器。

09 / 自己添加 REST

把一个 API 变成角色的工具

API 是服务留给程序调用的入口。你负责连接入口，角色负责每次填参数。例如把“查询快递”的接口包装成角色能理解的“查快递”工具。

先找接口，再创建工具。

只有网站首页或一段功能描述还不够。至少要有真实接口地址、请求方法、参数和鉴权方式。当前编辑器支持 GET / POST，其他请求方法不能直接照搬。

  1. 准备服务商 API 文档和你自己的访问凭据。
  2. 在 Tools → 添加单件 填名称、描述、地址和请求方式。
  3. 按文档填固定参数、请求头和 AI 参数定义。
  4. 保存并开启工具。
  5. 先执行一个容易核对的请求，查看实际返回结果。

GET、POST、鉴权与模板的完整例子

下面区分三种练习：已有网页 GET；不含凭据的 POST 回显；需要自己 Key 的真实搜索接口。请求头、参数、请求体的处理规则来自本项目执行器。

先记住实际合并规则

REST 模板规则
位置规则
固定参数同名时覆盖 AI 参数。字符串 true / false 会变成布尔值，数值形态会转成数字；像 00123 这种需保留前导零的值不要随意作为数值固定参数。
URL{{name}} URL 编码插入，{{{name}}} 原样插入。支持点路径；找不到参数会报错。
请求头可引用参数；已在 URL/请求头用掉的顶层参数，不会再次自动附到 GET 查询串。
GET其余参数编码后附到 query string，不发送 JSON 请求体；嵌套对象不要直接依赖自动字符串化。
POST，无请求体模板发送合并后的参数对象；默认 Content-Type 为 application/json。
POST，有模板仅发送模板渲染结果。整项 "{{repeat}}" 保留原始数字/布尔/对象类型；"数量：{{repeat}}" 是文本拼接。

Schema 是给模型看的输入定义，不应把所有 enum/minimum/required 都当作宿主已严格执行的校验。服务自身仍应验证请求。REST 编辑器只提供 GET/POST + JSON；没有任意 PATCH/DELETE、表单文件上传的通用配置。

连接与返回限制

新建 REST 工具缺省按浏览器直连处理；本手册例子明确关闭直连。网页内“无超时限制”的文案不准确：当前直连 fetch 等待响应阶段设置 120 秒中止计时，服务端代理通常也有 120 秒上限，部署平台还可能更短。

多个工具共用的返回截断上限为 2,000 字符。JSON 被截断后可能不再合法；请求时减少条数、只取所需字段，或让服务返回精简结果。二进制、媒体等部分路径会另行处理附件，不能把 2,000 字符当作所有文件的统一大小限制。

其他 MCP 的授权怎么填？

按服务文档选择：无需鉴权就留空；要求 Authorization: Bearer … 时把令牌填到访问 Token；要求其他 Header 时填请求头；支持 OAuth 时使用授权按钮。不是每个 MCP 都支持 OAuth。Token 栏与 Authorization 请求头同时填时，当前实现以 Token 栏为准。

我有 VPS，可以自己做一个 MCP 吗？

可以。例如“生活记录 MCP”提供记录心情、查询最近记录、统计打卡三个动作，数据实际保存在你的服务里。

  1. 确定动作与数据范围，例如日期、心情、备注。
  2. 开发并部署 MCP 服务，提供 Streamable HTTP 接口和所需存储。
  3. 配置 HTTPS 地址、鉴权和允许的操作范围。
  4. 在小手机添加服务器并发现工具。
  5. 新增一条测试记录，再重新查询它。

这是后续可开发的方案，当前没有替你部署。小手机“添加 MCP 服务器”只保存连接配置，不会自动在 VPS 安装软件或创建数据库。

什么时候用“直连模式”？

关闭直连时，请求经过小手机部署站点的服务端代理；公网 HTTPS 服务通常先用这种方式。该代理拒绝本机和内网地址。

开启直连后，由正在使用小手机的浏览器发请求。浏览器要能访问目标，服务要允许跨域（CORS），且使用 Streamable HTTP；HTTPS 页面访问 HTTP 内网地址也可能受浏览器限制。

手机上的 localhost 是手机自身，不是电脑，也不是 VPS。电脑上启动的服务要提供手机实际可访问的地址；不确定时优先使用正确配置的远程 HTTPS 服务。

工具描述告诉角色何时使用；名称与描述先进入提示词，具体动作按需获取。
访问 Token仅填令牌值，宿主按 Bearer 发送；输入 Bearer 前缀会被清理。与 Authorization 请求头冲突时 Token 栏优先。
请求头按服务文档填写，例如 x-api-key。不要同时在多处配置相互冲突的鉴权。
OAuth 授权仅适用于支持此流程的服务。允许弹窗，登录正确账号并确认工作区；返回小手机后再发现工具。
发现工具初始化后请求 tools/list。应出现真实动作名、说明和参数；改 URL 或权限后重新发现。
启用服务器开关控制是否提供给角色；当前界面没有为每个发现动作设置独立权限开关。

"""Private demonstration MCP. Start explicitly; no background service is installed."""
import os
import secrets

import uvicorn
from mcp.server.fastmcp import FastMCP
from mcp.server.transport_security import TransportSecuritySettings
from starlette.middleware.base import BaseHTTPMiddleware
from starlette.middleware.cors import CORSMiddleware
from starlette.responses import JSONResponse

token = os.environ["DEMO_MCP_TOKEN"]
if len(token) < 24:
    raise ValueError("DEMO_MCP_TOKEN 至少使用 24 个随机字符")
origin = os.environ.get("DEMO_UI_ORIGIN", "https://float.yanny.top")
public_host = os.environ.get("DEMO_MCP_HOST", "127.0.0.1:8765")
server = FastMCP(
    "时间换算演示",
    json_response=True,
    stateless_http=True,
    transport_security=TransportSecuritySettings(
        enable_dns_rebinding_protection=True,
        allowed_hosts=[public_host, "127.0.0.1:8765", "localhost:8765"],
        allowed_origins=[origin],
    ),
)


@server.tool()
def minutes_to_seconds(minutes: int) -> dict:
    """将 0 到 1440 分钟换算为秒，不读取文件或个人资料。"""
    if not 0 <= minutes <= 1440:
        raise ValueError("minutes 必须介于 0 和 1440")
    return {"minutes": minutes, "seconds": minutes * 60}


class TokenGate(BaseHTTPMiddleware):
    async def dispatch(self, request, call_next):
        supplied = request.headers.get("authorization", "")
        if not secrets.compare_digest(supplied, "Bearer " + token):
            return JSONResponse({"error": "访问 Token 不正确"}, status_code=401)
        return await call_next(request)


# CORS is outside the token gate so browser preflight can complete.
app = CORSMiddleware(
    TokenGate(server.streamable_http_app()),
    allow_origins=[origin],
    allow_methods=["GET", "POST", "DELETE"],
    allow_headers=["Content-Type", "Authorization", "MCP-Protocol-Version", "Mcp-Session-Id"],
    expose_headers=["Mcp-Session-Id"],
)

if __name__ == "__main__":
    uvicorn.run(app, host=os.environ.get("DEMO_MCP_BIND", "127.0.0.1"), port=8765)

停止、嵌套和脚本边界

步骤按顺序执行；任一步失败立即停止，不回滚已经完成的外部写入。一次组合调用内部的步骤不等于模型轮数。最多允许顶层组合再调用一层子组合，继续嵌套会报“层级过深”。不能靠循环嵌套制造无限工作流。

脚本支持 await / return，并运行在浏览器环境，可访问 window、document、localStorage、fetch 等；它不是隔离沙箱，也没有承诺自动中止所有脚本的统一超时。只导入你信任的脚本；纯数据整理通常只需要 input、steps 和 return。

工具轮数上限怎么选？

顶部可设 3 / 5 / 8 / 12 / 20，默认 5。限制一条消息最多进行几轮调用，每轮对应一次模型请求，同轮可以有多条动作。基础查询先保留 5，确认需要更多步骤后再提高。更多轮可能增加等待时间和模型用量，不会解决错误的接口配置。

刚才的任务没有完成。请告诉我实际调用的工具名、哪一步失败，以及工具返回的错误；不要输出密钥或 Token。如果没有发起调用，也请明确说明。

03 / 收件箱与自动联动

现实里发生一件事，角色就知道

上传快捷指令模板

所有 A 通道的自动化都长一个样，只有触发条件和 payload 不同。搭好一条后用「复制」改条件即可。

  1. 快捷指令 → 自动化 → 新建，选触发条件。
  2. 添加「获取 URL 内容」。URL 粘贴上传地址，删掉 [文件名]，原位插入「当前日期」变量，点变量把日期格式改「自定义」填 yyyyMMddHHmmss，后面保留 .json。文件名同时决定顺序和唯一性。

  5. 关闭「运行前询问」，保存，手动运行一次，回向导第 3 步点「刚发了测试数据？点此刷新」。

06 / 状态快照与主动查询

角色随时看你的手机状态

和收件箱不同，这里是覆盖写：iPhone 定期把最新状态写到固定文件 bridge-state/<key>.json，角色聊天时调工具读，回复自动带「更新于 N 分钟前」。

  1. 现实桥 → 主动查询 → 新建数据项。名称是角色看到的工具名（≤20 字，如「查看健康数据」），标识是文件名（小写字母数字下划线，如 health），说明写给角色看（≤200 字）。最多 30 项。

08 / 快捷动作

角色替你操作 iPhone

登记一个「动作名 + 快捷指令名 + 参数 + 结果模式」，角色就能像用工具一样调用。两种送达方式：

通知点击 vs 邮件自动
通知点击运行（默认）邮件自动运行（实验）
原理个人云推一条系统通知，你点通知 → 跳 shortcuts:// 运行站点发一封带标记的邮件，iOS「收到邮件时」自动化立即运行
需要你操作点一下通知不用
额外条件离线推送已开站点配 Resend，验证收件邮箱，iCloud / Exchange 邮箱才能秒收
适合要你在场确认的动作（发消息、拍照、截屏）无需确认的（开灯、写备忘录、切歌）
结果模式「不需要结果」发出即算完成；「等文本」快捷指令要把结果 POST 回来；「等图片」可回传图片（≤8MB，可附 OCR 文字）。等待 30 秒～15 分钟，默认 2 分钟。参数给角色填的坑，简易模式一行一个（名字 / 文本或数字 / 描述）。角色调用时自动组成 JSON 送给快捷指令。

快捷指令怎么搭

向导第 5 步会按你的选择动态生成清单，通用骨架如下。

  1. 快捷指令标签页新建（不是自动化），名字和登记的「快捷指令名」一字不差。
  2. 接参数：「获取文本」（输入：快捷指令输入）→「获取字典值」，字典选「文本」，键名填参数名。每个参数一次。
  3. 干正事（写备忘录、拍照、调 HomeKit…）。
  4. 回传文本：「获取字典值」取 resultUrl →「获取 URL 内容」POST 到它，请求体 JSON，文本字段 text 填结果。
  5. 回传图片：同上取 resultUrl。只传图：请求体选「文件」放图片。图 + 文字：先「Base64 编码」，请求体 JSON 放 image 和 ocr。
  6. 自己手动跑一次，再到向导第 6 步「发送测试通知」走整条链路。参数会自动填「来自小手机的测试」。
快捷指令收到的输入 · 你登记的参数 + 两个固定字段
{"memo":"记得买牛奶","commandId":"cmd_…","resultUrl":"https://<你的项目>.supabase.co/functions/v1/push-shortcut-result?command=cmd_…&ticket=…"}
回传文本 · POST 到 resultUrl
{"text":"在杭州西湖区，晴 26°C"}
回传图片 + 文字 · POST 到 resultUrl
{"image":"<Base64>","ocr":"屏幕上提取到的文字"}
邮件模式多一步。

自动化 → 新建「电子邮件」自动化：发件人填页面显示的地址，主题「包含」页面显示的 [FloatBridge:shortcut_…] 标记，选「立即运行」，动作 = 运行这条快捷指令并把邮件正文作为输入。邮件正文就是上面那段 JSON。

角色怎么触发

在线角色在工具循环里发 [执行动作:动作名({...})]，聊天里出现「已发送「X」到 iPhone」，结果回来后接着回。离线个人云生成回复时，角色在正文里写 【快捷动作：动作名({"参数":"值"})】，标记会被剥掉再执行，一次回复最多执行一个。结果回来 30 秒内你没打开小手机，云端会替角色再生成一句接结果的话推给你。限额同时最多 10 条待执行，1 分钟最多 6 次，超过报 429。

现象对照表

现象原因 / 处理

历史里备注「还在触发间隔内」冷却在起作用，按规则计时。改小或清 0。
历史里是「仅存档（无匹配规则）」信号名不一致。匹配是严格相等，大小写、空格都算。
