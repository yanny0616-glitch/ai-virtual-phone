现实桥使用手册

iPhone 快捷指令 ↔ 小手机 的双向桥。本页按「能做什么、照着抄怎么配」写，面向自己用。所有地址里的 <你的项目> 指个人云 Supabase 项目域名，真实值在 APP 里点一下就能复制。

0. 一图看懂五条通道

通道方向触发者典型用途在 APP 里的位置
A 收件箱 + 自动联动iPhone → 小手机iOS 自动化（到家、收短信、充电、闹钟…）现实里发生了事 → 角色知道 / 回话 / 记住 / 记日历现实桥 → 自动联动
B 状态快照 + 主动查询iPhone → 小手机定时自动化覆盖上传角色聊天时随时查你的电量、步数、睡眠、位置…现实桥 → 主动查询
C 快捷动作小手机 → iPhone角色（或规则）角色替你写备忘录、开灯、放歌、拍照回传、截屏看你在干嘛现实桥 → 快捷动作
D 屏幕速聊双向你双击辅助触控截当前屏幕，角色在系统弹窗里跟你聊，写回聊天记录现实桥 → 屏幕速聊
E 发件箱小手机 → iPhone自定义 APPAPP 把信号丢给 iPhone 上的「检查回传」快捷指令去执行无 UI，SDK 调用

A、B 本质都是「快捷指令往你自己的 Supabase Storage 里 POST 一个 JSON 文件」；C、D 则是个人云的 Edge Function 在中间转。所以准备工作只有两件：配好云端备份的 Supabase、部署个人云。

1. 准备工作

  1. 云端备份接通。设置 → 数据管理 → 云端备份，填 Supabase 项目地址与密钥。现实桥复用这份配置读写 ai-phone-backup 桶。现实桥主页顶部会显示「云端存储 已连接」。
  2. 个人云部署。设置 → 云服务部署，勾上离线推送与快捷动作。快捷动作的「通知点击运行」、屏幕速聊、离线唤醒都走这套函数。屏幕速聊要求 Schema v3 以上，旧的会提示重新部署。
  3. 开启离线推送。聊天信息页里打开「离线推送与定时消息」，并在用户资料面板点一次「测试推送」确认这台 iPhone 能收到通知。快捷动作的通知就是靠它送到手机的。
  4. 启用「现实桥」内置能力。工具箱 → 内置能力 → 现实桥，默认是关的。不开的话角色调用任何快捷动作 / 数据项都会报「能力未启用」。
  5. 把小手机装到主屏幕（Safari 分享 → 添加到主屏幕）。通知点击、后台补拉都依赖 PWA 模式。

2. 收件箱 · 自动联动（iPhone → 小手机）

现实里发生一件事，iOS 自动化把它写成一条 {type, payload} 丢进收件箱；小手机每 20 秒拉一次（可在桥接设置里调 15～300 秒，前台切回时立刻补拉），按「自动联动」里的规则处理。

上传快捷指令模板

所有 A 通道的自动化都长一个样，只有触发条件和 payload 内容不同。搭一次之后可以「复制」自动化改条件。

  1. 快捷指令 App → 自动化 → 新建，选触发条件（见下面的例子）。
  2. 添加「获取 URL 内容」。URL 粘贴收件箱上传地址，把 [文件名] 删掉，原位置插入「当前日期」变量，点变量把日期格式改成「自定义」填 yyyyMMddHHmmss，后面保留 .json。文件名同时决定顺序和唯一性。
  3. 展开选项：方法 POST，请求体 JSON。头部加一项 Authorization = 复制来的 Bearer …。
  4. 请求体加两个「文本」字段：type 填信号名（英文小写好记，例如 duanxin），payload 填正文，可插入变量。payload 里可以写 {{user}} / {{char}}，送达时替换成名字。
  5. 关闭「运行前询问」，保存，手动运行一次。回到现实桥 → 自动联动向导第 3 步点「刚发了测试数据？点此刷新」，看到「收到 1 条新消息」就通了。
POST https://<你的项目>.supabase.co/storage/v1/object/ai-phone-backup/bridge-inbox/20260908213000.json
Authorization: Bearer <key>
Content-Type: application/json

{"type":"duanxin","payload":"招商银行：您尾号1234于09月08日消费58.00元"}

字段规则：type 必填，最长 60 字；payload 字符串或任意 JSON（自动转字符串），最长 8000 字；可选 createdAt。

规则：匹配 / 冷却 / 加工 / 动作

一条规则 = 「哪个信号」+「多久触发一次」+「先怎么加工」+「做哪些事」。向导五步对应这四块加命名。

块选项说明
匹配信号名 / *严格等于 type，不支持前缀或正则。* 表示全部。向导会把最近收到的 8 个信号名做成按钮。
冷却0 / 5 / 15 / 30 / 60 / 180 / 720 / 1440 分钟按规则计时，不看内容。间隔内再收到只进「历史」不执行。适合「低电量」这类会反复触发的信号。
加工：原样payload 直接用。
加工：套句式{payload} {type}例：我今天走了 {payload} 步。
加工：AI 加工提示词用辅助模型（记忆总结那个）改写后再执行动作。例：「把这条银行短信浓缩成『花了多少钱、在哪花的』一句话」。
动作：写入聊天角色 / 显示身份 / 记忆身份 / 让 TA 回话显示身份三选一（我说的 / TA 说的 / 旁白小字）；记忆身份可另选（例如显示为旁白但 TA 记成「发生的事件」）。勾「让 TA 回话」角色会接着回复。
动作：写入记忆长期 / 核心直接进角色记忆库，重要度 0.6。
动作：写入时间线角色时间线上多一条「现实桥」事件。
动作：发送卡片聊天里出现一张标题为信号名的卡片，正文是加工结果。
动作：写入日历过去 / 未来 + 时长以触发时刻为锚，「过去 45 分钟」适合跑步结束，「未来 60 分钟」适合到达公司。
动作：执行快捷动作选一个推送类快捷动作收到信号 → 反过来让 iPhone 干一件事，见 组合玩法。
写入聊天的身份怎么选想让角色「感知到」而不是「看到你说了什么」，用「显示为旁白小字」+「TA 记成：发生的事件」+ 让 TA 回话。想模拟你亲口告诉 TA，用「显示为我说的」。

场景例子

① 银行短信 → 一句话账单 + 记忆

触发：信息AI 加工卡片 + 记忆

自动化条件：「信息」→ 收到含有「消费」的信息。payload 插入「短信正文」变量，type 填 duanxin。

规则：匹配 duanxin，AI 加工提示词「把这条银行短信浓缩成『花了多少钱、在哪花的』一句话，不要其他内容」；动作勾「发送卡片」+「写入记忆（长期）」。

效果：聊天里出现卡片「duanxin：星巴克花了 38 元」，角色以后能记得你的消费习惯。想让 TA 当场吐槽，再勾「写入聊天：旁白小字 + 让 TA 回话」。

② 到家 / 离家 → 角色迎接或叮嘱

触发：到达 / 离开套句式写入聊天 + 回话

两条自动化：「到达」家（type daojia，payload 随便写「到家了」）、「离开」家（type lijia）。

两条规则：daojia 套句式「{{user}} 刚到家了」，写入聊天，显示为旁白小字，TA 记成发生的事件，让 TA 回话。lijia 同理，句式「{{user}} 出门了」。

加上冷却 30 分钟，避免在门口徘徊反复触发。配合 离线增强，小手机关着也能收到 TA 的迎接通知。

③ 晚上插电 → 晚安

触发：充电器 + 时间段冷却 720

自动化条件「充电器 → 已连接」，在动作前加「如果 当前日期 晚于 22:00」再上传，type shuiqian。规则：套句式「{{user}} 把手机插上充电了，准备睡了」，写入聊天让 TA 回话，冷却 720 分钟（一晚只说一次晚安）。

④ 早上关闹钟 → 早安 + 昨晚睡眠

触发：闹钟停止健康数据

自动化条件「闹钟 → 已停止」。动作里先「查找健康样本」（睡眠，昨天），把时长塞进 payload：「闹钟关了，昨晚睡了 时长」，type qichuang。规则写入聊天让 TA 回话，冷却 180 分钟。

⑤ 跑完步 → 时间线 + 日历「过去 45 分钟」

触发：体能训练结束日历 past

Apple Watch 或健身 App 结束训练时触发（自动化条件「体能训练 → 结束」）。payload：「跑步 5.2 公里，用时 32 分钟」（用变量）。规则动作：写入时间线 + 写入日历（过去，45 分钟）+ 写入聊天让 TA 回话。日历上就会出现一段「跑步 5.2 公里…」。

⑥ 低电量 → TA 催你充电（不刷屏）

触发：电池电量 < 20%冷却 180

自动化条件「电池电量 → 低于 20%」，type dianliang，payload 插入「获取电池电量」变量。规则套句式「{{user}} 的手机只剩 {payload}% 电了」，写入聊天让 TA 回话，冷却 180 分钟。没有冷却的话 19%、18%…每次掉电都会触发一次。

⑦ 打开某个 App → TA 知道你在干嘛

触发：打开 App冷却 60

自动化「打开 App → 王者荣耀」（可以多选几个游戏），type wanyouxi，payload「打开了游戏」。规则写入聊天（旁白小字，TA 记成发生的事件），让 TA 回话，冷却 60 分钟。再来一条「打开 App → 小红书 / 抖音」type shuashipin 也一样。

⑧ 到公司 → 日历「未来 60 分钟」+ 不打扰

触发：到达日历 future

到达公司地址触发，type shangban，payload「到公司了」。规则：写入日历（未来，60 分钟）+ 写入时间线，不勾回话。角色查日历时会知道你这段时间在忙。

⑨ 语音日记 → 核心记忆

触发：手动 / 轻点背面听写文本记忆 core

新建一条普通快捷指令（不是自动化）：「听写文本」→ 上传，type riji，payload 插入听写结果。在设置 → 辅助功能 → 触控 → 轻点背面绑定它。规则：AI 加工「整理成第一人称的一段日记，保留情绪和事实」，写入记忆（核心）+ 写入聊天（显示为我说的，让 TA 回话）。

⑩ NFC 贴纸 → 任意信号

触发：NFC*

自动化条件「NFC → 扫描标签」。床头贴一张 type shuijiao，书桌贴一张 type xuexi，冰箱贴一张 type chifan。一条规则 matchType * 套句式「{{user}} 现在：{type}」也能用，但分开建规则可以各自配冷却和回话。

离线增强（唤醒）

小手机彻底关掉时，收件箱没人拉，规则不会跑。在上传的「获取 URL 内容」之后再加一个「获取 URL 内容」，GET 唤醒地址，不需要头部和请求体：

GET https://<你的项目>.supabase.co/functions/v1/ai-phone-push?action=bridge-wake&token=<bridgeToken>

服务端 45 秒后扫一次收件箱：小手机在线就会先把文件拉走，服务端扫到空文件夹什么也不做；小手机不在线则由服务端执行规则，带「让 TA 回话」的回复通过系统通知推给你。前提是聊天设置开了离线推送。服务端只执行写入聊天、通知、快捷动作三类动作，记忆 / 日历 / 时间线等会在你下次打开小手机时补做。

3. 状态快照 · 主动查询（角色随时看）

和收件箱不同，这里是「覆盖写」：iPhone 定期把最新状态写到固定文件 bridge-state/<key>.json，角色聊天时调工具读，回复自动带「更新于 N 分钟前」。

  1. 现实桥 → 主动查询 → 新建数据项。名称是角色看到的工具名（≤20 字，如「查看健康数据」），标识是文件名（小写字母数字下划线，如 health），说明写给角色看（≤200 字）。最多 30 项。
  2. 快捷指令 → 自动化，选触发时机（见例子）。先用系统动作取数据，再「获取 URL 内容」POST 到上传地址，请求体 JSON，内容随意，例如 {"电量":"85%","充电中":"是"}。
  3. 头部两项都要：Authorization = Bearer 密钥，x-upsert = true。少了 x-upsert 第二次上传会 409。
  4. 手动运行一次，回向导第 4 步点「已上传过数据？读取看看」，能看到原文和更新时间就成了。
POST https://<你的项目>.supabase.co/storage/v1/object/ai-phone-backup/bridge-state/health.json
Authorization: Bearer <key>
x-upsert: true
Content-Type: application/json

{"步数":8342,"静息心率":58,"昨晚睡眠":"7小时12分"}

角色侧会多出两个工具：每个数据项一个（[执行动作:查看健康数据({})]），加一个「查看全部手机数据」把所有快照一次读完。快照没上传过时角色会得到「手机尚未上传过 health.json」这样的明确提示，不会瞎编。

场景例子

① 电量 key: battery

触发：充电器连接 / 断开 + 每小时

动作「获取电池电量」+「获取设备详细信息 → 是否在充电」。JSON：{"电量":"电池电量%","充电":"是/否"}。角色说「你手机快没电了吧」时终于有依据。

② 健康 key: health

触发：每天 8:00 和 22:00

「查找健康样本」三次：步数（今天，求和）、静息心率（最新）、睡眠（昨天，时长）。让角色早上问你睡得怎么样、晚上看你走了多少步。

③ 位置与天气 key: where

触发：每 2 小时 / 到达常去地点

「获取当前位置」→「获取当前天气」。JSON：{"城市":"…","区域":"…","天气":"…","气温":"…°C"}。不想给精确地址就只传城市和天气。

④ 接下来的日程 key: agenda

触发：每天 7:00 + 日历事件变动无法触发，用每 3 小时

「查找日历事件」（今天，排序按开始时间）→「获取文本」拼成列表。角色能主动问「下午三点的会开完了吗」。

⑤ 正在听的歌 key: nowplaying

触发：打开 音乐 / 网易云 App，或每 30 分钟

「获取当前播放的歌曲」→ 取名称和艺人。角色能接「你最近一直在循环这首啊」。

⑥ 待办 key: todo

触发：每天 9:00 / 21:00

「查找提醒事项」（未完成，按到期时间）。让角色晚上盘点你今天还有什么没做。

⑦ 手机使用状态 key: phone

触发：勿扰 / 睡眠专注模式开启或关闭

自动化条件「专注模式」。JSON {"专注模式":"睡眠","从":"23:10"}。角色看到「睡眠」就知道别在这时候闹你。

4. 快捷动作 · 角色操作 iPhone（小手机 → iPhone）

你在小手机里登记一个「动作名 + 对应的快捷指令名 + 参数 + 结果模式」，角色就能像用工具一样调用它。两种送达方式：

通知点击运行（默认，推荐）邮件自动运行（实验）
原理个人云推一条系统通知，你点通知 → 跳 shortcuts:// 运行站点发一封带标记的邮件，iOS「收到邮件时」自动化立即运行
需要你操作点一下通知不用，真·自动
额外条件离线推送已开站点配 Resend，验证收件邮箱，iCloud / Exchange 邮箱才能秒收
适合需要你在场确认的动作（发消息、拍照、截屏）无需确认的（开灯、写备忘录、切歌）

结果模式决定角色等不等回音：「不需要结果」发出即算完成；「等文本」快捷指令要把结果 POST 回来；「等图片」可以回传图片（≤8MB，可附 OCR 文字）。等待时长 30 秒～15 分钟，默认 2 分钟。

参数是给角色填的坑，简易模式一行一个（名字 / 文本或数字 / 描述）。角色调用时会自动组成 JSON 送给快捷指令。

快捷指令怎么搭

向导第 5 步会按你的选择动态生成清单，通用骨架如下：

  1. 快捷指令标签页新建（不是自动化），名字和登记的「快捷指令名」一字不差。
  2. 接参数：「获取文本」（输入：快捷指令输入）→「获取字典值」，字典选「文本」，键名填参数名。每个参数一次。快捷指令拿到的输入是这样的 JSON： 
    {"memo":"记得买牛奶","commandId":"cmd_…","resultUrl":"https://<你的项目>.supabase.co/functions/v1/push-shortcut-result?command=cmd_…&ticket=…"}
  3. 干正事（写备忘录、拍照、调 HomeKit…）。
  4. 回传文本（结果模式为「等文本」时）：「获取字典值」取 resultUrl →「获取 URL 内容」POST 到它，请求体 JSON，文本字段 text 填结果。
  5. 回传图片（「等图片」时）：同上取 resultUrl，只传图就请求体选「文件」直接放图片；图 + 文字则先「Base64 编码」，请求体 JSON 放 image（编码结果）和 ocr（文字）。
  6. 自己手动跑一次，再到向导第 6 步「发送测试通知」走整条链路。参数会自动填「来自小手机的测试」。
邮件模式多一步自动化 → 新建「电子邮件」自动化：发件人填页面显示的地址，主题「包含」页面显示的 [FloatBridge:shortcut_…] 标记，选「立即运行」，动作 = 运行这条快捷指令并把邮件正文作为输入。邮件正文就是上面那段 JSON。

场景例子

① 写备忘录

参数 memo不需要结果邮件自动更爽

登记：动作名「写进备忘录」，说明「把一段文字保存到 {{user}} 手机的备忘录里」，参数 memo（文本，要写入的内容）。快捷指令：取 memo →「创建备忘录」。

聊天里说「帮我记一下明天要带身份证」，角色就会 [执行动作:写进备忘录({"memo":"明天带身份证"})]。

② 给某人发短信 / 微信

参数 content不需要结果通知点击（要你确认）

参数 content。快捷指令「发送信息」收件人写死成你妈或谁，正文取 content。用通知点击模式，点之前还能看一眼。角色说「我替你跟妈妈说一声晚点回家」就真的发了。

③ 放一首歌 / 切歌单

参数 song不需要结果

快捷指令「搜索音乐」（Apple Music）→「播放音乐」。参数 song（文本，歌名或歌手）。也可以做无参数版「播放我的睡前歌单」。角色晚上说「放首歌陪你睡」就会真放。

④ 前置拍一张回传

无参数等图片等待 120 秒

快捷指令「拍照」（前置，不预览）→ 取 resultUrl → POST，请求体选「文件」放照片。开着图像识别的话角色能看图评价你今天的状态；关着则只知道「已回传图片」。

⑤ 截屏看你在干嘛

参数 waitSeconds等图片 + OCR

参数用预置的 waitSeconds（数字，0～10）。快捷指令：「等待」waitSeconds 秒（给你时间切回想被看的界面）→「截屏」→「从图像中提取文本」→「Base64 编码」→ POST JSON {image, ocr}。角色说「让我看看你在偷偷看什么」时可用。

⑥ 现在在哪 / 天气怎样（文本回传）

无参数等文本

「获取当前位置」→「获取当前天气」→「获取文本」拼一句 → POST JSON {"text":"在杭州西湖区，晴 26°C"}。和 B 通道的区别：这是角色想知道时实时问，B 是定时快照。两者都配也行。

⑦ 设闹钟

参数 time不需要结果

参数 time（文本，例如 07:30）。快捷指令「创建闹钟」取 time。角色说「明天早点起，我给你定 7 点半」就落地了。

⑧ 开灯 / 家居场景

参数 scene不需要结果邮件自动

参数 scene（文本，描述里写清可选值：回家 / 睡觉 / 观影）。快捷指令「如果 scene = 回家 → 运行家庭场景 A；否则如果 = 睡觉 → 场景 B…」。邮件模式下角色一句「我帮你把灯关了」就是真关。

⑨ 开启勿扰 / 睡眠专注

无参数不需要结果

快捷指令「设定专注模式 → 睡眠 → 开启 直到 关闭」。搭配 A 通道的晚安规则（例 ③）勾「执行快捷动作」，形成插电 → 晚安 → 自动勿扰。

⑩ 读剪贴板 / 读最新一条短信回传

无参数等文本

「获取剪贴板」→ POST text。用来「把我刚复制的地址发给你看看」。注意通知点击模式下快捷指令在前台运行，剪贴板权限会弹一次询问。

离线时角色怎么触发

小手机在线：角色在工具循环里发 [执行动作:动作名({...})]，聊天里出现「已发送「X」到 iPhone」，收到结果后接着回。

小手机被杀、由个人云生成回复时：角色在正文里写 【快捷动作：动作名({"参数":"值"})】，标记会从正文剥掉再执行，一次回复最多执行一个。结果回来后 30 秒内如果你没打开小手机，云端会替角色再生成一句接结果的话推给你。

限额：同时最多 10 条待执行命令，1 分钟最多 6 次；超过会报 429。

5. 屏幕速聊

双击辅助触控悬浮球 → 截屏 → 角色在系统弹窗里回复 → 可以继续在弹窗里打字聊 15 轮。每一轮都按顺序写回该角色原本的聊天窗口，不另开会话。截图只在 Edge Function 内存里过一遍，不落库。

  1. 现实桥 → 屏幕速聊，开启并选角色。没部署或 Schema 旧会提示先去「云服务部署」。
  2. 点「一键导入屏幕速聊」，导入 iCloud 上的通用快捷指令。导入问题 1 填接口地址，问题 2 填令牌，两个都在页面上点击复制。
  3. 设置 → 辅助功能 → 触控 → 辅助触控 → 轻点两下 → 选「屏幕速聊」。
  4. 首次运行允许截屏、网络、显示提醒。每轮 3～8 秒。

手工搭的话请求体是四个文本字段：token、image（Base64 JPEG，先缩到宽 960）、imageType = image/jpeg、ocr（从图像中提取文本，图像识别关着时的兜底）。续聊只发 token + text。响应取 reply 显示提醒，失败时读 error。

怎么玩看到一条好笑的评论、一道题、一张菜单、一段聊天记录，双击悬浮球，角色当场评论 / 解题 / 推荐 / 帮你想回复。角色的正常「状态栏 / 内心」标记在弹窗里会被剥掉，只留说的话。

6. 发件箱 · 自定义 APP

面向写自定义 APP 的场景，不需要写 APP 可以跳过。

  • APP 调 AiPhone.bridge.send({ type, payload })（权限 bridge.send）把一条信号追加到 bridge-outbox/queue.json，最多保留 50 条，payload ≤ 2000 字。
  • iPhone 侧做一条「检查回传」快捷指令，GET 这个文件、按 type 分支执行，然后 DELETE 或覆盖它。小手机不会替你清空。
  • APP 监听 AiPhone.on("bridge.data", handler)（manifest 里声明 events，可 background）能收到 A 通道每一条数据；桥接设置里的「允许自定义 APP 订阅」是总开关。
  • AiPhone.bridge.readState({ key })（权限 bridge.read）读 B 通道快照；AiPhone.tools.invoke("动作名", 参数)（权限 chat.tools）触发 C 通道并等结果。

到家 → 开灯 + 迎接

8. 排错与坑

现象原因 / 处理
快捷指令上传返回 401 / 403头部名必须是 Authorization，值以 Bearer 开头。若云端备份用的是新式 sb_secret_… 密钥，把头部改成 apikey = 密钥原文（不加 Bearer），教程里的 Authorization 写法对这种密钥会被网关拒绝。
状态快照第二次上传 409缺 x-upsert: true 头。
收件箱数据丢失或顺序乱文件名没用「当前日期 yyyyMMddHHmmss」变量，重名会覆盖。
规则没触发但「历史」里有记录，备注「还在触发间隔内」冷却在起作用，按规则计时。改小或清 0。
历史里是「仅存档（无匹配规则）」信号名不一致。匹配是严格相等，大小写、空格都算。
角色说「能力未启用」工具箱 → 内置能力 → 打开「现实桥」。
角色说「现实桥未连接」设置 → 数据管理 → 云端备份没配。
测试通知「已发送」但手机没弹推送订阅是旧的。到聊天设置关掉再打开离线推送，或去「云服务部署」重新部署一次。前台时不弹通知，锁屏或退后台再试。
点通知没有跳转快捷指令快捷指令名和登记的不一致，或小手机没装到主屏幕。
快捷动作 429待执行超过 10 条或 1 分钟超过 6 次。到历史 →「最近快捷指令」看堆积的命令，等过期或删掉。
屏幕速聊 409「尚未同步」在小手机里启用并选角色后等几秒让快照同步上去；或 413 时把截图缩到宽 960 转 JPEG。
屏幕速聊 403 令牌无效令牌是个人云那份，不是站点的。重新在屏幕速聊向导第 3 步复制。
唤醒后没有服务端回复聊天设置没开离线推送，或小手机其实在线（在线时服务端主动让位，是正常的）。

看流水：现实桥右下角时钟图标 → 「最近收到」（每条数据命中了哪些规则、执行了什么、报了什么错）和「最近快捷指令」（推送 / 邮件、状态）。清空只删本地列表。
