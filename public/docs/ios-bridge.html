01
约 2 分钟 · 只需要云端备份已接通

完成你的第一条联动

  1. 打开现实桥 → 自动联动 → 新建，向导第 2 步点一下上传地址和密钥各复制一份。
  2. iPhone「快捷指令」→ 新建普通快捷指令，加一个「获取 URL 内容」：URL 粘贴地址并把 [文件名] 换成「当前日期」变量（格式 yyyyMMddHHmmss），方法 POST，头部 Authorization 粘贴密钥，请求体 JSON 加两个文本字段 type = test、payload = 你好呀。
  3. 运行它，回到向导第 3 步点「刚发了测试数据？点此刷新」。
  4. 看到「收到 1 条新消息」，信号名按钮里出现 test，就通了。

成功的样子：现实桥主页「今日收到」变成 1，历史里有一条 type 为 test 的记录，备注「仅存档（无匹配规则）」。

本页只是说明，不会读取你的配置。所有默认值来自源码，你设备上的设置可能不同。

02 / 准备工作

五件事，做一次就够

  1. 云端备份接通。设置 → 数据管理 → 云端备份，填 Supabase 项目地址与密钥。现实桥复用这份配置读写 ai-phone-backup 桶，主页顶部显示「云端存储 已连接」即可。
  2. 个人云部署。设置 → 云服务部署，勾上离线推送与快捷动作。快捷动作的通知、屏幕速聊、离线唤醒都走这套函数。屏幕速聊要求 Schema v3 以上，旧的会提示重新部署。
  3. 开离线推送。聊天信息页打开「离线推送与定时消息」，在用户资料面板点一次「测试推送」，杀掉后台等 6 秒能收到通知才算通。
  4. 启用「现实桥」内置能力。工具箱 → 内置能力 → 现实桥，默认关闭。不开的话角色调任何快捷动作或数据项都会报「能力未启用」。
  5. 小手机装到主屏幕。Safari 分享 → 添加到主屏幕。通知点击、后台补拉都依赖 PWA 模式。

03 / 收件箱与自动联动

现实里发生一件事，角色就知道

iOS 自动化把事件写成一条 {type, payload} 丢进收件箱；小手机每 20 秒拉一次（桥接设置里可调 15～300 秒，切回前台立刻补拉），按「自动联动」里的规则处理。

上传快捷指令模板

所有 A 通道的自动化都长一个样，只有触发条件和 payload 不同。搭好一条后用「复制」改条件即可。

  1. 快捷指令 → 自动化 → 新建，选触发条件。
  2. 添加「获取 URL 内容」。URL 粘贴上传地址，删掉 [文件名]，原位插入「当前日期」变量，点变量把日期格式改「自定义」填 yyyyMMddHHmmss，后面保留 .json。文件名同时决定顺序和唯一性。
  3. 展开选项：方法 POST，请求体 JSON。头部加 Authorization = 复制来的 Bearer …。
  4. 请求体加两个「文本」字段：type 填信号名（英文小写好记），payload 填正文，可插入变量。payload 里可写 {{user}} / {{char}}，送达时替换成名字。
  5. 关闭「运行前询问」，保存，手动运行一次，回向导第 3 步点「刚发了测试数据？点此刷新」。
快捷指令实际发出的请求 · 对照用
POST https://<你的项目>.supabase.co/storage/v1/object/ai-phone-backup/bridge-inbox/20260908213000.json
Authorization: Bearer <key>
Content-Type: application/json

{"type":"duanxin","payload":"招商银行：您尾号1234于09月08日消费58.00元"}

type 必填，最长 60 字。payload 字符串或任意 JSON（自动转字符串），最长 8000 字。可选 createdAt。

规则的四块

一条规则 = 哪个信号 + 多久触发一次 + 先怎么加工 + 做哪些事。向导五步对应这四块加命名。

规则选项 · 全部来自向导
块选项说明

执行快捷动作选一个推送类快捷动作收到信号后反过来让 iPhone 干一件事，见第 12 章。
身份怎么选。

想让角色「感知到」而不是「看到你说了什么」：显示为旁白小字 + TA 记成发生的事件 + 让 TA 回话。想模拟你亲口告诉 TA：显示为我说的。

05 / 离线增强

小手机关着，规则照样跑

小手机彻底关掉时收件箱没人拉。在上传的「获取 URL 内容」之后再加一个「获取 URL 内容」，GET 唤醒地址，不需要头部和请求体。

唤醒请求 · token 换成自己的
GET https://<你的项目>.supabase.co/functions/v1/ai-phone-push?action=bridge-wake&token=<bridgeToken>

服务端 45 秒后扫一次收件箱。小手机在线就会先把文件拉走，服务端扫到空文件夹什么也不做；不在线则由服务端执行规则，带「让 TA 回话」的回复通过系统通知推给你。

服务端只做三类动作。

写入聊天、通知、快捷动作。记忆、日历、时间线会在你下次打开小手机时补做。前提是聊天设置已开离线推送。

06 / 状态快照与主动查询

角色随时看你的手机状态

和收件箱不同，这里是覆盖写：iPhone 定期把最新状态写到固定文件 bridge-state/<key>.json，角色聊天时调工具读，回复自动带「更新于 N 分钟前」。

  1. 现实桥 → 主动查询 → 新建数据项。名称是角色看到的工具名（≤20 字，如「查看健康数据」），标识是文件名（小写字母数字下划线，如 health），说明写给角色看（≤200 字）。最多 30 项。
  2. 快捷指令 → 自动化，选触发时机。先用系统动作取数据，再「获取 URL 内容」POST 到上传地址，请求体 JSON，内容随意。
  3. 头部两项都要：Authorization = Bearer 密钥，x-upsert = true。少了 x-upsert 第二次上传会 409。
  4. 手动运行一次，回向导第 4 步点「已上传过数据？读取看看」，能看到原文和更新时间即可。
快照上传请求 · 注意 x-upsert
POST https://<你的项目>.supabase.co/storage/v1/object/ai-phone-backup/bridge-state/health.json
Authorization: Bearer <key>
x-upsert: true
Content-Type: application/json

{"步数":8342,"静息心率":58,"昨晚睡眠":"7小时12分"}

角色侧会多出两个工具：每个数据项一个，加一个「查看全部手机数据」一次读完。没上传过时角色会得到「手机尚未上传过 health.json」的明确提示，不会瞎编。

角色调用格式 · 给角色参考
[执行动作:查看健康数据({})]
[执行动作:查看全部手机数据({})]

08 / 快捷动作

角色替你操作 iPhone

登记一个「动作名 + 快捷指令名 + 参数 + 结果模式」，角色就能像用工具一样调用。两种送达方式：

通知点击 vs 邮件自动
通知点击运行（默认）邮件自动运行（实验）
原理个人云推一条系统通知，你点通知 → 跳 shortcuts:// 运行站点发一封带标记的邮件，iOS「收到邮件时」自动化立即运行
需要你操作点一下通知不用
额外条件离线推送已开站点配 Resend，验证收件邮箱，iCloud / Exchange 邮箱才能秒收
适合要你在场确认的动作（发消息、拍照、截屏）无需确认的（开灯、写备忘录、切歌）
结果模式「不需要结果」发出即算完成；「等文本」快捷指令要把结果 POST 回来；「等图片」可回传图片（≤8MB，可附 OCR 文字）。等待 30 秒～15 分钟，默认 2 分钟。参数给角色填的坑，简易模式一行一个（名字 / 文本或数字 / 描述）。角色调用时自动组成 JSON 送给快捷指令。

快捷指令怎么搭

向导第 5 步会按你的选择动态生成清单，通用骨架如下。

  1. 快捷指令标签页新建（不是自动化），名字和登记的「快捷指令名」一字不差。
  2. 接参数：「获取文本」（输入：快捷指令输入）→「获取字典值」，字典选「文本」，键名填参数名。每个参数一次。
  3. 干正事（写备忘录、拍照、调 HomeKit…）。
  4. 回传文本：「获取字典值」取 resultUrl →「获取 URL 内容」POST 到它，请求体 JSON，文本字段 text 填结果。
  5. 回传图片：同上取 resultUrl。只传图：请求体选「文件」放图片。图 + 文字：先「Base64 编码」，请求体 JSON 放 image 和 ocr。
  6. 自己手动跑一次，再到向导第 6 步「发送测试通知」走整条链路。参数会自动填「来自小手机的测试」。
快捷指令收到的输入 · 你登记的参数 + 两个固定字段

角色怎么触发

在线角色在工具循环里发 [执行动作:动作名({...})]，聊天里出现「已发送「X」到 iPhone」，结果回来后接着回。离线个人云生成回复时，角色在正文里写 【快捷动作：动作名({"参数":"值"})】，标记会被剥掉再执行，一次回复最多执行一个。结果回来 30 秒内你没打开小手机，云端会替角色再生成一句接结果的话推给你。限额同时最多 10 条待执行，1 分钟最多 6 次，超过报 429。
09 / 动作场景

10 个让角色真的动手的动作

01 · 写备忘录memo · 不需要结果
登记动作名「写进备忘录」，说明「把一段文字保存到 {{user}} 手机的备忘录里」，参数 memo（文本）快捷指令取 memo →「创建备忘录」送达邮件自动最顺手，通知点击也行
角色会发出的调用
[执行动作:写进备忘录({"memo":"明天带身份证"})]
02 · 给某人发短信content · 要你确认
参数content（文本）快捷指令「发送信息」，收件人写死，正文取 content送达通知点击，点之前还能看一眼

角色说「我替你跟妈妈说一声晚点回家」就真的发了。

03 · 放一首歌 / 切歌单song · 不需要结果
参数song（文本，歌名或歌手）快捷指令「搜索音乐」→「播放音乐」；也可做无参数版「播放睡前歌单」
04 · 前置拍一张回传无参数 · 等图片
快捷指令「拍照」（前置，不预览）→ 取 resultUrl → POST，请求体选「文件」放照片等待120 秒

开着图像识别的话角色能看图评价你今天的状态；关着则只知道「已回传图片」。

05 · 截屏看你在干嘛waitSeconds · 等图片 + OCR
参数预置的 waitSeconds（数字，0～10）快捷指令「等待」waitSeconds 秒 →「截屏」→「从图像中提取文本」→「Base64 编码」→ POST JSON {image, ocr}

等待那几秒是给你切回想被看的界面。

06 · 现在在哪 / 天气怎样无参数 · 等文本
快捷指令「获取当前位置」→「获取当前天气」→「获取文本」拼一句 → POST {"text":"…"}

和第 06 章快照的区别：这是角色想知道时实时问，快照是定时的。两者都配也行。

07 · 设闹钟time · 不需要结果
参数time（文本，例如 07:30）快捷指令「创建闹钟」取 time
08 · 开灯 / 家居场景scene · 邮件自动
参数scene（文本，描述里写清可选值：回家 / 睡觉 / 观影）快捷指令「如果 scene = 回家 → 运行家庭场景 A；否则如果 = 睡觉 → 场景 B…」
09 · 开启勿扰 / 睡眠专注无参数
快捷指令「设定专注模式 → 睡眠 → 开启 直到 关闭」联动第 04 章场景 03 的晚安规则勾「执行快捷动作」，插电 → 晚安 → 自动勿扰
10 · 读剪贴板回传无参数 · 等文本
快捷指令「获取剪贴板」→ POST text

「把我刚复制的地址发给你看看」。通知点击模式下快捷指令在前台运行，剪贴板权限会弹一次询问。

10 / 屏幕速聊

双击悬浮球，截屏跟 TA 聊

双击辅助触控 → 截屏 → 角色在系统弹窗里回复 → 可以继续在弹窗里打字聊 15 轮。每一轮都按顺序写回该角色原本的聊天窗口。截图只在 Edge Function 内存里过一遍，不落库。

  1. 现实桥 → 屏幕速聊，开启并选角色。没部署或 Schema 旧会提示先去「云服务部署」。
  2. 点「一键导入屏幕速聊」，导入 iCloud 上的通用快捷指令。导入问题 1 填接口地址，问题 2 填令牌，都在页面上点击复制。
  3. 设置 → 辅助功能 → 触控 → 辅助触控 → 轻点两下 → 选「屏幕速聊」。
  4. 首次运行允许截屏、网络、显示提醒。每轮 3～8 秒。
手工搭时的请求体 · 首轮四个字段，续聊只发 token + text
{"token":"<bridgeToken>","image":"<Base64 JPEG，先缩到宽 960>","imageType":"image/jpeg","ocr":"<从图像中提取文本>"}

{"token":"<bridgeToken>","text":"那帮我看看第二个菜"}

响应取 reply 用「显示提醒」弹出，失败时读 error。角色的「状态栏 / 内心」标记在弹窗里会被剥掉，只留说的话。

怎么玩。

看到一条好笑的评论、一道题、一张菜单、一段聊天记录，双击悬浮球，角色当场评论、解题、推荐、帮你想回复。

11 / 发件箱与自定义 APP

写 APP 才用得到

SDK 四个入口
能力调用权限
收：监听现实信号AiPhone.on("bridge.data", handler)manifest extensions.events 声明 bridge.data，可 background
发：回传给 iPhone 执行AiPhone.bridge.send({ type, payload })bridge.send
查：读手机状态快照AiPhone.bridge.readState({ key })bridge.read
唤：触发快捷动作并等结果AiPhone.tools.invoke("快捷动作名", 参数)chat.tools

bridge.send 把信号追加到 bridge-outbox/queue.json，最多保留 50 条，payload ≤ 2000 字。iPhone 侧做一条「检查回传」快捷指令，GET 这个文件、按 type 分支执行，再 DELETE 或覆盖它。小手机不会替你清空。桥接设置里的「允许自定义 APP 订阅」是 bridge.data 的总开关。

13 / 排错与上限

现象对照表

先看历史流水（右下角时钟图标），再对照这张表
现象原因 / 处理
快捷指令上传 401 / 403头部名必须是 Authorization，值以 Bearer 开头。若云端备份用的是新式 sb_secret_… 密钥，改成头部 apikey = 密钥原文（不加 Bearer），Bearer 写法对这种密钥会被网关拒绝。
快照第二次上传 409缺 x-upsert: true 头。
收件箱数据丢失或顺序乱文件名没用「当前日期 yyyyMMddHHmmss」变量，重名会覆盖。
历史里备注「还在触发间隔内」冷却在起作用，按规则计时。改小或清 0。
历史里是「仅存档（无匹配规则）」信号名不一致。匹配是严格相等，大小写、空格都算。
角色说「能力未启用」工具箱 → 内置能力 → 打开「现实桥」。
角色说「现实桥未连接」设置 → 数据管理 → 云端备份没配。
测试通知「已发送」但没弹推送订阅是旧的。聊天设置关掉再打开离线推送，或去「云服务部署」重新部署。前台不弹通知，锁屏或退后台再试。
点通知没跳快捷指令快捷指令名和登记的不一致，或小手机没装到主屏幕。
快捷动作 429待执行超过 10 条或 1 分钟超过 6 次。历史 →「最近快捷指令」看堆积的命令，等过期或删掉。
屏幕速聊 409「尚未同步」在小手机里启用并选角色后等几秒；413 时把截图缩到宽 960 转 JPEG。
屏幕速聊 403 令牌无效令牌是个人云那份，不是站点的。重新在屏幕速聊向导第 3 步复制。
唤醒后没有服务端回复聊天设置没开离线推送；或小手机其实在线，服务端主动让位，是正常的。
