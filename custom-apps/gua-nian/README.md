# 挂念

让角色过上自己的一天，并在她的一天里「想起你」。灵感来自 AstrBot 的私人陪伴类插件，但按 Float 的能力重新设计，不是移植。

## 她怎么想起你

1. **生成今日生活面** — `ai.generate`（预设 `guanian-daily`）按人设生成她今天的心情、精力、位置和 6–9 条日程。
   会先 `calendar.read` 读取她在系统日程 app 里今天已定的安排，作为必须保留的固定项；生成结果再经 `calendar.write` 写回系统日程（条目 id 以 `guanian_` 开头，重新生成时只清理自己写入的，不动手动条目）。
2. **编排心动时刻** — 从日程里取未来的时间点（避开免打扰时段），一次 `ai.generate`（预设 `guanian-impulse`）让她逐个复核：做完那件事之后，她会不会真的想发消息？act=true 的才给出第一人称动机 intent。
3. **预约离线主动消息** — 对通过复核的时刻调用 `AiPhone.push.wake({ characterId, fireAt, intent })`。服务端挂载成功显示「离线可达」（浏览器关了也能收到推送）；失败降级为「仅在线」（本地轮询触发）并显示原因。
4. **此刻预览** — 预设 `guanian-preview` 基于她当下状态生成一条她此刻会说的话，只展示不发送、不占额度。
5. **诊断** — 每个候选时刻为什么发 / 为什么没发、预约结果，都记录在面板底部的诊断区。

## 设置

- 挂念的人（默认取启动上下文的角色，可切换）
- 免打扰时段（跨零点也支持；免打扰开始前 20 分钟会自动追加一个「睡前」候选时刻）
- 每日主动上限（1–6）

## 权限

`app.data.read/write`（本 app 数据）、`characters.read`、`ai.generate`、`calendar.read/write`（与系统日程互通）、`push.wake`（离线主动消息，主程序权限，随本 app 一并落地）、`ui.toast`。

## 数据

`db` 集合：`settings`（单条配置）、`days`（每角色每天一条生活面）、`plans`(每角色每天一条编排结果)、`logs`（诊断日志，保留最近 40 条）。
