# 外卖

逛店点餐、用钱包付款、看着外卖在地图上一步步送到。能给角色点一份、请 TA 代付，TA 也会在聊天里主动给你点；聊天时 TA 知道外卖到哪了，送到之前不会问你好不好吃。

开发时编辑 `src/` 下的文件，运行 `npm run waimai:build` 合成 `index.html` 并更新随宿主发布的 zip；请勿直接改生成的 `index.html`。目录和关键决定见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 安装

应用市场 → 导入安装包，确认权限（角色、用户资料、生成、读写聊天、发卡片、请求回复、聊天上下文、通知、定时任务、钱包读取与支付、APP 数据）。安装包约 55KB，不带图片和外部资源：封面是 CSS 画的，图标是 emoji 和内联 SVG。

## 用法

- **首页**：左上角是收货地址，点开能改。下面是搜索、热词、十个分类、天天红包（每天一张）、招牌推荐和商家列表。列表可以按评分 / 起送价 / 配送速度排序，也可以只看有满减的或收藏的店。本地搜不到时可以让 AI 现编几家店（「我的」里可关）。
- **店铺**：点菜 / 评价 / 商家三个标签页。点菜页左边是分类、右边是菜；奶茶咖啡选温度和甜度，面、烧烤这类选辣度。底部购物车条点开是抽屉，可以加减、清空。右上能收藏。
- **结算**：在这里选送给谁（自己或某个角色）、填地址和备注、选送达时间（尽快 / 30 分钟后 / 1 小时后 / 指定）。付款方式是钱包付款或找 TA 代付；红包自动抵扣。
- **订单**：全部 / 进行中 / 待评价。进行中的订单上面是地图，骑手沿路线走；可以催单、改配送速度。送到后可以打分、再来一单。遇到少送或洒漏可以申请退款，退成红包。
- **我的**：红包、收货地址和忌口、配送速度和小插曲开关、和聊天联动的几个开关、收藏的店、AI 店铺和订单清理。

## 和聊天的联动

| 方向 | 怎么触发 | 发生什么 |
|---|---|---|
| 我给 TA 点 | 结算页选 TA，或聊天「+」面板里「给TA点外卖」 | 聊天里出现一张外卖卡片；送达时卡片改成已送达、写一条历史、可以请 TA 回一句 |
| 请 TA 代付 | 结算页选「找 TA 代付」 | 发代付卡片并请 TA 回复；TA 用 `[外卖代付:同意/拒绝:想说的话]` 回应，同意才开始配送，拒绝后可以改成自己付 |
| TA 给我点 | TA 在回复里写 `[点外卖:店铺:餐品:想说的话]` | APP 没打开也会建单、开始配送、发通知；店名对不上已有的店也照样建单，按卡片上写的店名和餐品显示 |
| TA 知道进度 | 「让 TA 知道外卖进度」开着 | 和这位角色有关的在途 / 刚送到的订单会写进聊天上下文，别的角色看不到 |

问「TA 想吃什么」走 `presets.json` 里的 `waimai-crave` 预设，回一行 `[想吃:关键词:一句话]`，关键词可以直接拿去搜店。

## 已知限制

- 月售、距离、好评度是按店名和菜名算出来的装饰数字，不是统计。
- 钱包没有退款接口，取消已付款订单和赔付都发成红包。
- 送达通知靠宿主定时任务；整个手机页面关着时任务不跑，下次打开才补上。
- 地图是示意图，骑手位置每 2 秒跟着重绘跳一下。
