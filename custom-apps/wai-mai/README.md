# 外卖

逛四十来家店点餐、用钱包付款、看着外卖在地图上一步步送到；也能到店自取、跑腿帮买、领券抽奖开会员。能给角色点一份、请 TA 代付、和 TA 拼单、请群聊吃，把店、购物车、订单分享给 TA，还能让角色当骑手；TA 也会在聊天里主动给你点。聊天时 TA 知道外卖到哪了，送到之前不会问你好不好吃。

开发时编辑 `src/` 下的文件，运行 `npm run waimai:build` 合成 `index.html` 并更新随宿主发布的 zip；请勿直接改生成的 `index.html`。目录和关键决定见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 安装

应用市场 → 导入安装包，确认权限（角色、用户资料、生成、读写聊天、发卡片、请求回复、聊天上下文、通知、定时任务、钱包读取与支付、APP 数据）。安装包约 85KB，不带图片和外部资源：封面是 CSS 画的，图标是 emoji 和内联 SVG。

## 用法

- **首页**：左上角是收货地址（地址簿，家 / 公司 / 学校…）。下面是搜索、热词、十个分类、五个入口（领券中心、天天抽奖、会员、跑腿帮买、买过的店）、天天红包、招牌推荐和 39 家内置店。列表可以按评分 / 起送价 / 配送速度排序，只看有满减的、收藏的或买过的店；翻到底可以让 AI 再找几家（「我的」里可关）。
- **店铺**：点菜 / 评价 / 商家三个标签页，每家每天有一道七折的「今日特价」。可以切到店自取（不收配送费，再减一成，最多减 10 元）；部分店有当天的店铺红包。右上能分享给 TA、收藏。
- **结算**：选送给谁（自己、某个角色、记住的群聊）、地址、送达时间。有包装费；会员或运费券免配送费；「顺手带一件」一键加几块钱的小东西。付款方式：钱包付款、找 TA 代付、和 TA 拼单（一人一半）。请群聊时可以每样按人数点。
- **领券中心**：每天 4 张平台券（含运费券）+ 6 家店的店铺券，一键全领；天天抽奖一天一次。券有门槛、限店和有效期，下单时自动挑最划算的。
- **会员**：月卡 ¥15 / 季卡 ¥39，外卖配送免运费、跑腿减 3 元，每月送 4 张红包，记着省了多少。
- **跑腿帮买**：选去超市 / 药店 / 便利店 / 水果店 / 就近，写下要买的东西和估价，骑手去店里买齐了送来。
- **订单**：全部 / 进行中 / 待评价 / 退款售后，右上「管理」能批量删已完成的。配送中可以催单、改速度、给骑手捎句话；自取单显示取餐码，做好后点「我已取餐」。送到后评价、给骑手好评差评和打赏、晒单给 TA；售后可选少送（退那一份）、洒了（退一半餐费）、送错（整单退）、太慢（退配送费），累计不超过实付，退成红包。
- **我的**：会员入口、券包、地址簿和忌口、配送速度、谁来送（选一位角色当骑手）、和聊天联动的开关、收藏的店、AI 店铺和订单清理。

## 和聊天的联动

| 方向 | 怎么触发 | 发生什么 |
|---|---|---|
| 我给 TA 点 | 结算页选 TA，或聊天「+」面板里「点外卖」 | 聊天里出现一张外卖卡片；送达时卡片改成已送达、写一条历史、可以请 TA 回一句 |
| 请 TA 代付 | 结算页选「找 TA 代付」 | 发代付卡片并请 TA 回复；TA 用 `[外卖代付:同意/拒绝:想说的话]` 回应，同意才开始配送，拒绝后可以改成自己付 |
| 和 TA 拼单 | 结算页选「和 TA 拼单」 | 你先付一半，发拼单卡片；TA 用 `[外卖拼单:同意/拒绝:想说的话]` 回应，同意才开始配送，拒绝后可以自己补上另一半或取消（已付的退成红包） |
| 请群聊 | 在群聊「+」面板点「点外卖」进来一次，之后首页和结算页都能选这个群 | 宿主不能往群会话里发卡片，所以群里靠不分角色的那份聊天上下文知道你请客、外卖到哪了；订单页「看看大家怎么说」用群聊生成（`waimai-group` 预设）让每人说一句 |
| 分享给 TA | 店铺页「分享」、购物车抽屉「让 TA 帮我看看」、送达后「晒单」 | 往 TA 的聊天里发一张卡片和一条历史，默认请 TA 回一句 |
| 角色当骑手 | 「我的 → 谁来送」 | 之后的单由 TA 送，地图上是 TA 的头像；TA 的上下文里知道自己在给谁送、送到没有，打赏会写进 TA 的聊天 |
| TA 给我点 | TA 在回复里写 `[点外卖:店铺:餐品:想说的话]` | APP 没打开也会建单、开始配送、发通知；店名对不上已有的店也照样建单，按卡片上写的店名和餐品显示 |
| TA 知道进度 | 「让 TA 知道外卖进度」开着 | 和这位角色有关的在途 / 刚送到的订单会写进聊天上下文，别的角色看不到 |

问「TA 想吃什么」走 `presets.json` 里的 `waimai-crave` 预设，回一行 `[想吃:关键词:一句话]`，关键词可以直接拿去搜店。

## 已知限制

- 月售、距离、好评度是按店名和菜名算出来的装饰数字，不是统计。
- 钱包没有退款接口，取消已付款订单和赔付都发成红包。
- 送达通知靠宿主定时任务；整个手机页面关着时任务不跑，下次打开才补上。
- 地图是示意图，骑手位置每 2 秒跟着重绘跳一下。
- 请群聊：宿主的 `chat.sendCard` / `writeHistory` / `requestReply` 只认角色私聊，群里看不到卡片，只能靠上下文知道。
- 自己开店（经营模式）还没做。
