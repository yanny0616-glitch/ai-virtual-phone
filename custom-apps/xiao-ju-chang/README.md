# 小剧场

给一个角色和它绑定的世界书，点一下生成一篇小剧场：可能是一段小说体，也可能是 AI 当场写的一整页 HTML（弹幕、聊天截图、论坛帖、可翻的塔罗牌）。整段 HTML/JS 在沙盒 iframe 里直接渲染，不走正则。

开发时编辑 `src/` 下的文件，运行 `npm run xjc:build` 合成 `index.html` 并更新随宿主发布的 zip；请勿直接改生成的 `index.html`。目录和关键决定见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 安装

应用市场 → 导入安装包，确认权限（角色、用户资料、生成、裸通道、读聊天、写记忆、媒体、APP 数据）。安装包约 47KB，不带任何外部资源。

## 概念

一个**小剧场**是一次组合，四类部件各自成库，随便换：

| 部件 | 是什么 |
|---|---|
| 前置要求 | 整段 system 框架。默认两条：重约束版（把人设世界书降级成参考材料，只输出任务要的东西）和轻量版 |
| 提示词 | 标题 + 内容 + 标签。场景、if 线、文字形式、前端形式都在这一个库里，按标签区分，一个小剧场可以叠好几条 |
| 随机池 / 随机宏 | 池子按标签抽 0～5 条追加进任务；宏是写在提示词里的 `{{随机词:世界}}` `{{随机数:好感}}`，APP 自己展开 |
| 输出方式 | 纯文字 / HTML / 两者混排，标签包裹名，篇幅，HTML 风格约束（不约束 / 给主题变量 / 严格只用主题色），HTML 可开「分两步出」：先要页面骨架立刻渲染，再按占位编号填字 |

每个组合还单独存：记忆三选一（跟宿主记忆 / 最近 N 轮聊天 / 不带）、是否写回一条长期记忆（默认关）、我在戏里是谁（宿主用户人设 / 自定身份 / 旁观）、纯裸通道（默认关）、随机权重。

## 用法

- **舞台**：选主演和本期小剧场，底部悬浮条上「生成一篇」；或者「随机」（按权重抽）、「AI 自选」（把形式库列给模型自己挑）。生成时逐字显示（设置里「边写边显示」，默认开；纯文字直接出现在页面里，HTML 先只报字数，分两步出的第二步直接填进格子），显示已等秒数，可以取消（宿主那次调用不能中断，回来的结果直接丢掉）。结果紧跟在本期卡下面，标题行有全屏，正文下面是再来一条 / 收藏 / 复制。AI 写的按钮带 `data-action` 时，点一下会接着那个选择再生成一篇。
- **小剧场**：四个标签页分别管组合、提示词、随机、前置。点一个组合进编辑页，提示词可以排序、增删，随机按标签只抽或排除。支持批量导入（`## 标题 #标签` 的纯文本，或本 APP 导出的 JSON、暗柜「夜间档案」JSON）；其它 JSON（酒馆预设、角色卡、别人的生成器导出）会递归扫出像提示词的段落，勾选后导成提示词 / 前置要求 / 随机条目。
- **收藏**：roll 到好看的存下来，展开能看到当时用的前置、提示词、抽中的随机、输出设置、记忆模式和模型，一键「按这套再来一条」。没收藏的结果按设置里的条数保留在「最近」。
- **设置**：外观（四套主题、字号、行距、动效）、生成（篇幅限制与默认篇幅、「边写边显示」、新建组合的默认值、随机与最近条数）、数据（导出导入、补齐默认库、清空、重置）。

四套主题不只是换色：杂志是衬线标题加编辑排版，便签墙是彩色便签，终端是等宽暗色，剧本是场次加台词缩进。
