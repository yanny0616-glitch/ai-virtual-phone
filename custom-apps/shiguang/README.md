# 拾光

按角色收藏你们的共同经历。聊到设定轮数就自动整理值得记住的小事；普通私聊会根据你当前说的话，在回复前找出相关记忆。每条发给角色的摘要都看得见、改得了。

## 安装

应用市场 → 导入安装包，确认权限（读聊天、后台监听、注入提示词、调用模型、APP 数据）。2.0 之前的拾光记录会在第一次打开时自动接续。

整理用的模型：在「绑定配置」里给拾光绑一个 API（推荐记忆总结用的那个）；没绑就用该角色的聊天模型。

## 用法

- **记忆本**：搜索、按类型/发送方式筛选；每张卡片都显示「选中后发给 AI 的内容」。
- **编辑与摘要**：改摘要、发送方式（优先携带 / 按话题回忆 / 不发送）、关键词、故事细节、进展和约定日期。
- **回看原消息**：定位到这条记忆来自哪几句聊天。
- **整理新消息**：手动整理一批；「还有未整理的消息」时再点一次继续。
- **回忆规则**：总开关、自动整理开关、整理间隔（轮）、回忆预算（Token）、按角色的整理进度和「从头整理」。

## 版本

- 2.1.1：关键词整理覆盖简称、常用叫法和具体细节，并过滤重复与泛词。检索按词匹配标题和关键词，摘要及最新后续作为低权重补充；旧记忆无需重新整理即可受益。仍为本地文字匹配，不保证理解没有写出的同义表达。

- 2.1.0：普通私聊当轮召回，需要同时更新宿主。回复前只检索已有记忆，不额外调用模型；超时或失败时本轮省略拾光内容，聊天继续。其他场景仍沿用事件同步的上下文；旧宿主保持原来的召回时机。

- 2.0.3：记忆摘要没有变化时也刷新提示词注入，避免宿主跨天或 6 小时过期后继续聊天仍缺少记忆。提示词查看器中，拾光位于聊天历史之后「自定义 APP 实时状态」的 `【拾光】` 段落。

- 2.0.1：版面回到原来宿主面板那套：卡片折叠，展开看「发给 AI 的内容」和细节，编辑直接在卡片里，不再有全屏弹窗。

- 2.0.0：独立 APP，数据和逻辑全部在 APP 内；接续旧记录；摘要由模型直接写；优先携带最多占预算一半。
- 1.x：宿主页面的壳。
