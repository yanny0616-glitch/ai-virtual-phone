# 拾光 1.0.0

在小手机「应用市场」导入 `shiguang-1.0.0.zip`，安装后可添加到桌面。需要配套支持独立拾光接口的宿主版本；旧宿主会显示更新提示。

- 按角色搜索和筛选记忆，整理新消息，编辑事实、后续和关键词，回看关联原消息。
- 卡片显示「选中后发给 AI 的内容」。发送正文统一来自可编辑摘要，附上当前进展和后续；不会使用另外一份隐藏摘要。
- 发送方式：优先携带（预算内优先）、按话题回忆、不发送。每次请求的实际选取结果仍以该次提示词查看器/日志为准。
- 使用原有拾光数据库、配置和整理进度，不复制或清空记录。旧记录默认摘要来自已有标题、卡片简述、缘由、经过和具体信息；可编辑压缩，也可从卡片重新生成。
- 保存卡片详情后，请同步检查摘要；手动保存的摘要不会被自动整理覆盖，后续进展仍可补充。摘要超预算时整条跳过，卡片会提示。
- 整理与回忆设置对所有角色生效。模型调用使用宿主绑定的记忆总结模型，自动整理由宿主继续触发，不要求打开拾光 APP。
- 删除拾光需要确认；原聊天消息保留。过期编辑会拒绝覆盖，刷新后重新编辑。

本次无个人云函数或 SQL 变更。宿主仍提供原有备份与恢复；安装包不包含聊天或记忆数据。

开发：编辑 `src/`，运行 `npm run shiguang:build`；打包 `npm run shiguang:package`。`index.html` 为生成产物。
