# 拾光

按角色收藏你们的共同经历。聊到设定轮数就自动从聊天里整理出值得记住的小事，按话题带进下一次对话；每条发给角色的摘要都看得见、改得了。

## 安装

应用市场 → 导入安装包，确认权限（读聊天、后台监听、注入提示词、调用模型、APP 数据）。2.0 之前的拾光记录会在第一次打开时自动接续。

整理用的模型：在「绑定配置」里给拾光绑一个 API（推荐记忆总结用的那个）；没绑就用该角色的聊天模型。

## 用法

- **记忆本**：搜索、按类型/发送方式筛选；每张卡片都显示「选中后发给 AI 的内容」。
- **编辑与摘要**：改摘要、发送方式（优先携带 / 按话题回忆 / 不发送）、关键词、故事细节、进展和约定日期。
- **回看原消息**：定位到这条记忆来自哪几句聊天。
- **整理新消息**：手动整理一批；「还有未整理的消息」时再点一次继续。
- **回忆规则**：总开关、自动整理开关、整理间隔（轮）、回忆预算（Token）、按角色的整理进度和「从头整理」。
