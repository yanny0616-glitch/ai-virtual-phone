# 陪眠

睡前陪伴：角色用自己的声音在枕边说话，越说越轻；多层白噪音叠成你的声景；每晚一条夜记，周视图看作息。

开发时编辑 `src/` 下的文件，运行 `npm run pei-mian:build` 合成 `index.html` 并更新随宿主发布的 zip；请勿直接改生成的 `index.html`。目录和关键决定见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 安装

应用市场 → 导入安装包，确认权限（角色、用户资料、生成、语音、麦克风、媒体、写聊天、外网、APP 数据）。安装包约 15MB，内置 19 段声音。

## 用法

- **今夜**：选角色 → 选模式（哄睡 / 失眠 / 只要声音）→ 定时 → 「睡了」。入睡画面里长按麦克风可以说一句，TA 回一句；右下角按钮把屏幕压得更暗。第二天打开点「我醒了」，补自评和一句话。
- **声景**：点声音叠加（最多 6 层），每层独立音量，「起伏」让音量慢慢波动；「存组合」记住当前这套；右上角 + 打开声音商店（要在配置里填 Freesound API Key）；「导入」加自己的录音；长按一块试听或看来源。
- **话术**：节奏（几段、首/末段字数、间隔怎么拉长）、内容方向、禁止项；失眠模式单独一套；「试一句」按当前设置生成第一段并朗读。
- **夜记**：每天一条、每周汇总（柱状图、平均入睡、作息波动、达标次数、和上周比、TA 的一周观察）、每月月历。
- **配置**：主题（夜航日夜自动 / 暖烛 / 灰雾）、语音情绪、躺着说话开关、作息目标、渐弱时长、Freesound Key、是否写进聊天记录、早安一句、致谢、清空数据。
