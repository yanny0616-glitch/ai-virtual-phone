# 聊天插件

装法：设置 → 聊天插件 → 粘贴文件全文安装。

- `affection-ledger.js` 好感与关系。角色回复末尾的 `[内心]` 块里带心里话、好感变化量（−3～+3）、关系转折；插件截下来累加成慢变的好感，关系按角色各自存，由角色按人设自己定（第一轮直接采用），转折时按开关决定是问你还是TA自己改。面板入口在聊天输入栏「+」面板里。与挂念共用变量池：`affection`（scope character）。
- `presence-status.js` 在线状态。聊天列表头像上的点 + 聊天页名字下的一行小字（在线 / 忙碌 / 睡觉中 / 离开 / 隐身）。读变量池 `presence`（挂念写的此刻快照）和 `presenceOverride`（点名字下那行字手动锁定），作息从 `ctx.data.replyGate` 拿，挂念不开也按时间实时变。
- `moments-rhythm.js` 朋友圈节奏。把「发完一条等 24～48 小时到点必发」换成每小时掷一次骰子：概率 = 每周目标条数 × 时段权重（作息从 `ctx.data.replyGate` 拿，睡着 0、忙着 0.2）× 精力（变量池 `presence.energy`）× 事件加成（刚做完一件事、今天聊得多、好感刚涨）。由头会带进发帖提示词。装了挂念且开着「想分享时发朋友圈」的角色，骰子改由挂念掷（浏览器关着也掷，配速读挂念的设置），插件看到变量池里的 `moments` 就让位。
- `profile-signature.js` 个性签名。朋友圈主页上的签名由TA自己写：每次回消息时按概率（默认 8%，心情刚变过时翻倍，没签名时必问）允许在正文末尾写 `[签名]xxx` 换一句，插件截下来存进变量池 `profile`（scope character，`{signature, at, by}`），主页直接读它显示；你在主页上点签名也能替TA改（by=user）。
