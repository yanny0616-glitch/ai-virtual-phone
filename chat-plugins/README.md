# 聊天插件

装法：设置 → 聊天插件 → 粘贴文件全文安装。

- `affection-ledger.js` 好感与关系。角色回复末尾的 `[内心]` 块里带心里话、好感变化量（−3～+3）、关系转折；插件截下来累加成慢变的好感，关系按角色各自存，由角色按人设自己定（第一轮直接采用），转折时按开关决定是问你还是TA自己改。面板入口在聊天输入栏「+」面板里。与挂念共用变量池：`affection`（scope character）。
- `presence-status.js` 在线状态。聊天列表头像上的点 + 聊天页名字下的一行小字（在线 / 分神 / 忙碌 / 睡觉中 / 离开 / 隐身）。1.1.0：点那行字打开的面板里加了「固定作息」（每个角色一张：什么事、几点到几点、星期几、算睡觉 / 专注 / 忙 / 分神，存变量池 `routine`）和「今天的例外」（列出剧情改过的安排，× 撤销、可手动加）；装了忙碌回复 1.2 时，此刻状态由它按「手动 › 例外 › 固定作息 › 挂念」合起来算（bus `availability.query`），「本该睡了 · 还在陪你」这类说明也来自它。分神画成空心绿点。读变量池 `presence`（宿主按最新挂念日程计算）和 `presenceOverride`（手动状态优先）。前台宿主负责日程同步，不需要打开挂念；旧数据仍以 `ctx.data.replyGate` 作息与快照兜底。
- `moments-rhythm.js` 朋友圈节奏。把「发完一条等 24～48 小时到点必发」换成每小时掷一次骰子：概率 = 每周目标条数 × 时段权重（作息从 `ctx.data.replyGate` 拿，睡着 0、忙着 0.2）× 精力（变量池 `presence.energy`）× 事件加成（刚做完一件事、今天聊得多、好感刚涨）。由头会带进发帖提示词。装了挂念且开着「想分享时发朋友圈」的角色，骰子改由挂念掷（浏览器关着也掷，配速读挂念的设置），插件看到变量池里的 `moments` 就让位。
- `profile-signature.js` 个性签名。朋友圈主页上的签名由TA自己写：每次回消息时按概率（默认 8%，心情刚变过时翻倍，没签名时必问）允许在正文末尾写 `[签名]xxx` 换一句，插件截下来存进变量池 `profile`（scope character，`{signature, at, by}`），主页直接读它显示；你在主页上点签名也能替TA改（by=user）。
- `typing-rhythm.js` 打字节奏。回复切成的多条气泡按真人打字速度一条条放出：每条等待 = 字数 ÷ 每秒字数，再加随机浮动，夹在最短/最长之间；表情和图片按固定时长。等待期间聊天页顶部一直显示「对方正在输入」。速度、浮动、上下限、第一条要不要也等、开了流式是否照样按节奏放，都在插件设置里调。挂 `message.beforeReveal`，只改 `delayMs`，不落库不改文本。前台、后台忙碌回复和个人云回端消息均接入气泡节奏；云端回端仍先原子保存完整批次，再逐条展示。流式预览文字本身不由此钩子限速。

- `busy-reply.js` 忙碌回复。1.2.0：① 固定作息——没装挂念也按在线状态面板里的作息延后回复，装了挂念时固定作息优先，写了睡觉就不再用挂念的作息时间；② 今天的例外——提示词里列出接下来的安排，TA 在剧情里真的改了安排时附看不见的 `[作息:推迟|睡觉|03:00]` / `[作息:取消|上课]` / `[作息:加|14:00-16:00|去医院|忙]`，插件从正文拿掉并记成当天例外，当轮生效、过点失效；③ 分神——做饭、看剧这类「在做但不算忙」（固定作息标了分神，或挂念此刻在做的事），回复等 30～120 秒、话短，连发 3 条就放下手里的事，只在本机等、不上云；④ 打电话——挂 `call.beforeConnect`：睡着时响 20 秒，第一通 35%、5 分钟内第二通 70%、第三通必醒，没接到就在TA醒来后主动问你怎么了，叫醒后半小时内算醒着；专注中直接拒接（「在上课」），忙完回过来；一般忙按概率接；刚发过紧急词一定接。概率、响铃时长、连打间隔、回拨开关都在设置里。1.1.1 将状态提示改为中文摘要，仅包含当前状态、活动、地点、心情、精力、有效手动状态；不读取好感与关系变量，不重复注入关系或好感分数、同步元数据、内部 ID、好感历史或关系历史，原数据仍供面板使用。1.1.0 新增「允许角色选择不回复」（默认开启）：结合人设、关系、情绪、上下文和当前状态决定沉默，成功结束本轮，不生成气泡、通知或追问；新消息重新判断，仍会调用模型。需新版宿主、网关与 push-generate；群聊、通话、线下剧情和主动任务不启用。规则入口独立在「设置 → 聊天插件 → 忙碌回复」：控制等待间隔、专注偷空概率、睡眠回复、紧急消息优先和手动状态有效期。挂 `chat.replyGate`，读取挂念或其他 APP 的作息；没有挂念时可使用「在线状态」插件的手动忙碌/睡觉状态，没有状态就正常回复。首次读取导入旧挂念设置（包含关闭和 0），此后只认插件设置。宿主执行等待及个人云同步，插件不保存 API 密钥、不调用模型。停用或卸载后旧 APP 规则不复活；已有云端等待成功同步后释放，已经开始生成的请求保留。需搭配新版宿主，0.9.21 挂念只提供日程。
- `meetup.js` 约见面。输入栏「+」面板里约TA（现在 / 今晚 / 挑个时间，地点和想做什么可空），发出一张约见卡片并让TA回一轮；TA 按自己那时的日程在回复末尾写 `[约见答应]` / `[约见改时间:明天 20:00]` / `[约见推掉]`，插件截下标记改卡片状态。TA 也会自己约你（`[约见:时间|地点|想做什么]`），频率分关 / 偶尔 / 常常，另有「最多几天约一次」「推掉后几天不再约」两道冷却。约好后按「到点叫你」走宿主定时唤醒（App 关着走离线推送），卡片到点变「去赴约」，点了切进线下并注入这次见面的开场；线下顶部一条「这次见面 · 散场」，散场后用辅助模型写一句回执盖章。卡片三种样式（票根 / 简约 / 信笺），类名都以 `mt-` 开头可用自定义 CSS 改；每个角色可在聊天信息 → 约见面里单独设。需要新版宿主（`ctx.chat` 与 `chatInfo.section` 坑位）。
