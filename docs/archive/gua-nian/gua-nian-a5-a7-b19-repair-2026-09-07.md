## 边界与生效

旧历史缺少身份字段时，真实发生次数无法凭空还原。修复使不确定资料不再被当作确定的重复轮次；数据库原始数据保留，不声称已经精确修复每条旧消息身份。旧版已经丢弃的消息、已经改错的时间和历史排序不自动恢复。

跨页面保护针对同源、共享 IndexedDB、支持 Web Locks 的页面。不同设备或不同存储分区各保存自己的消息不属于同库重复；设备接管仍属 A6。没有 Web Locks 时明确记录暂停原因，保留云端消息，不能退回页面内锁冒充跨页面安全。已有外部动作或插件自身跨数据库事务的恢复语义没有扩大为全局恰好一次。

时区完全无法恢复时，需要打开新版挂念同步，故障解决后可用原有重试入口恢复。真实手机被挂起时的系统通知和展示时机仍不能保证。
