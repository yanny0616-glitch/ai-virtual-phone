# 拾光 2.1.1 当轮召回试用

本版包含配套宿主与拾光安装包。先更新宿主，再从记忆库打开拾光升级；仅在旧宿主安装 ZIP 不会启用当轮召回。

## 手机验证（发布后约 2 分钟）

1. 在记忆库点「打开拾光」，让宿主内置包升级到 2.1.1。
2. 找到一条已有记忆，确认发送方式为「按话题回忆」，并记下一个具体关键词。
3. 回到该角色的普通文字私聊，突然提起这个关键词。
4. 查看这次请求的提示词，在聊天历史后的「自定义 APP 实时状态 → 【拾光】」确认相关记忆已出现；无需再发第二句。

测试的是已有记忆的召回，不是刚说一句就立即生成新记忆。仍需启用拾光，并在当前预设保留自定义 APP 实时状态条目。无匹配或等待超过 2 秒时，本轮可以没有拾光块，聊天继续。手机关闭后的云端主动消息不在本次范围内。
