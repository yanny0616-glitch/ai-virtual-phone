# 信息页自动同步挂念状态

## 已实现

- 宿主在存储水合后启动同步；读取已选角色的本地日程，批量拉取个人云当日/前一日日程。进入会话与状态面板、角色选择/日程变动、联网、回前台、跨日触发核对。
- 每秒检查时钟，仅在状态变化或刷新间隔到时写变量；普通云端核对间隔 60 秒，纯读取不消耗 AI 调用。前台接收私有广播后重新鉴权读取日程；后台停止连接与请求，返回时恢复。
- 服务器在日程保存成功后广播 changed，仅传空通知、不传日程或聊天；推送失败不回滚已保存数据。无需新增数据库表或 SQL。
- 挂念与宿主共用 `lib/guanian-presence.ts`。手动状态优先，旧快照不能覆盖宿主状态。未同步本地修改、较新的本地计划版本受保护。跨日不会继续显示昨天的会议。
- 网络错误保留最后日程，信息面板提示正在用缓存；无可用日程时显示待同步。取消角色选择清除宿主管理的数据，面板关闭清理监听，局部更新不影响未保存输入。
